2. ETL
Instalar: python -m pip install -r requirements.txt
PowerShell desde la raíz:
$env:COOPDB_HOST="127.0.0.1"
$env:COOPDB_PORT="3306"
$env:COOPDB_USER="root"
$env:COOPDB_PASSWORD="TU_CLAVE"
$env:COOPDB_DATA_KEY="CLAVE_PRIVADA_DE_AL_MENOS_24_CARACTERES"
python .\etl\ejecutar_etl.py
Después ejecutar 04_Carga_Masiva_ETL/01_verificacion_etl.sql y guardar capturas de conteos y rechazos.

3. Aplicaciones
Compilar cada .csproj con .NET 8 en Windows. Asociados es WinForms; Seguridad y Finanzas son programas de consola independientes. Configurar variables de entorno según cada .env.example. No distribuir credenciales de administrador ni claves dentro de la aplicación.

4. Datos demo
Revisar primero 03_Operaciones_Financieras/24_datos_demo_y_pruebas.sql. Ejecutarlo solo en una base de pruebas vacía o después de comprobar que las referencias no se hayan usado. Algunas referencias son únicas y una segunda ejecución puede fallar por duplicidad.

5.Pruebas
Ejecutar los archivos de pruebas de forma separada. Para aislamiento, abrir dos conexiones Workbench y usar el mismo ID de cuenta de demostración. Mantener abierta la sesión A mientras se ejecuta el SELECT ... FOR UPDATE en B; documentar espera y liberación.
Para rollback, provocar el retiro superior al saldo en una cuenta demo, comprobar que no se insertó movimiento y que el saldo no cambió.
Para durabilidad, confirmar una operación, reiniciar el servicio MySQL de pruebas y consultar nuevamente el movimiento y saldo.
Para backup, usar backup/backup_restauracion.ps1 y capturar la restauración en una base de prueba.

6. BI
Ejecutar 05_Dashboards_BI/30_vistas_dashboards.sql. Conectar Power BI a MySQL y usar las vistas v_bi_* indicadas en el manual. Agregar segmentador por agencia y período; guardar el .pbix y capturas.
